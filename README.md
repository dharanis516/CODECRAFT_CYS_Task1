# CODECRAFT_CYS_Task1

A Python implementation of the Caesar Cipher. The program lets you enter a
message and a shift value to encrypt or decrypt text.

## Features
- Encrypt and decrypt messages
- Custom shift value (positive or negative)
- Preserves uppercase and lowercase letters
- Leaves numbers, spaces and punctuation unchanged

## How to run
python caesar_cipher.py

## Example
Message: Hello, World!
Shift: 3
Encrypted: Khoor, Zruog!
